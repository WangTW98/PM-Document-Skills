## 1. 页面目标与上下文

### 1.1 页面目标

- 页面目的：核对已选服务的 SKU、数量与最终应付金额，确认后创建订单。
- 用户目标：确认选购内容无误，快速进入支付。
- 业务目标：锁定购买意向，生成待支付订单。
- 页面成功标准：订单创建成功率。

### 1.2 页面入口与出口

| 类型 | 来源 / 去向 | 触发条件 | 传入 / 传出数据 | 备注 |
|---|---|---|---|---|
| 入口 | 服务商品详情 (U-310) | 点击“立即下单” | 商品 ID、SKU ID、购买数量 |  |
| 出口 | 支付收银台 (U-330) | 点击“提交订单”且成功 | 订单 ID、支付金额 |  |
| 出口 | 服务商品详情 (U-310) | 点击返回 | 无 |  |

### 1.3 角色与权限

|---|---|---|---|
| 客户用户 | 是 | 已登录 | 跳转登录页 |

### 1.4 全局页面属性
