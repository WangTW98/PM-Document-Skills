Detail + Drawer Pattern

Detail Card

详情页按信息分组组织，使用卡片与段落结构承载字段，不把所有字段堆在一个长表单内。

  • 基础信息
  • 状态轨迹
  • 关联对象
  • 操作记录

Drawer

优先用于行内编辑、详情预览、审批处理和局部配置，减少全页跳转。

Utilities and States

Radius

默认 `8px`，后台保持专业和节制。

Density

默认正文 `14px`，表格和筛选保持高可读紧凑。

Shadow

卡片弱阴影，浮层和抽屉才用更高层级阴影。

Focus

所有输入和按钮都必须有清晰 focus ring。

Responsive Behavior

Desktop

完整后台架构，Sidebar + Header + Table + Drawer。

Tablet

折叠导航、保留核心表格和抽屉。

H5

列表转摘要卡片，保留审批与查询主任务。

Mobile

任务流与待办优先，弱化复杂数据视图。

Key Tokens

  • `text.primary`

Anti-Drift Rules

  • 不要引入玻璃、拟物、营销官网风
  • 不要把所有内容塞进单个大白板
  • 不要让表格和筛选失去效率
  • 不要把手机端做成缩小桌面端
