Use the runner-neutral skill at `../../SKILL.md`.

1. Read `skill.yaml` for metadata and output contract.
2. Read `SKILL.md` for the workflow and release rules.
3. Read `references/release-quality-checklist.md` before finalizing output.
4. Load `product/development/product-overview-draft.md`.
5. Apply every release handling decision from the final `假设与待确认统一清单`.
6. Write `product/release/product-overview-release.md` only when all material assumptions and confirmations have concrete release handling.
7. Ensure the release document contains no `A-*`, `Q-*`, assumptions, open questions, or confirmation workflow sections.
