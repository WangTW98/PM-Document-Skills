Agent Anti-Drift Guidelines

  • Backgrounds: Page root is `#f8fafc`, container elements are `#ffffff`. Do not invert these.
  • Borders: Always use `1px solid #e2e8f0` to separate structural areas.
  • Buttons: Height is `40px` (`space.10`), not smaller. Radius is `6px`.
  • Text: Do not use pure `#000000`. Use `#0f172a` for titles, `#475569` for reading text.
  • Spacing: Use `16px` (`space.4`) or `24px` (`space.6`) for general padding. Tighten to `8px` (`space.2`) inside dense forms or tables.
